# Zero Hype — Apex site (zerohypelab.com)

> No fluff. No hype. Just what works.

This repository is the **apex / homepage** of ZeroHype Lab, an anonymous B2B marketing diagnostics brand. It serves [zerohypelab.com](https://zerohypelab.com/) — the hub that links out to every product.

## What lives here

- The homepage and hub ([index.html](https://zerohypelab.com/))
- Global assets: self-hosted fonts, favicon, OG image, `robots.txt`, `sitemap.xml`, `llms.txt` / `llms-full.txt`
- Hub pages: Manifesto, Method, About, Guides index, Wall of Scores
- The **Tartarus** codebase diagnostic ([/tartarus/](https://zerohypelab.com/tartarus/))
